# Библиотека — коллекции Java

Практическая работа: консольная программа на Java по теме **«Библиотека»**, которая показывает работу коллекций `List`, `LinkedList`, `Set` и `Map` для хранения, поиска и обработки книг.

Автор: Кулибаев Адилет, группа 24.246

## Как запустить

1. IntelliJ IDEA → **File → Open** → папка проекта.
2. Открыть `src/Main.java` и нажать зелёный ▶ рядом с `main`.
3. Если IntelliJ попросит JDK — **Download JDK** (подойдёт любая версия от 8).
4. В конце программа попросит ввести ID книги (1–100) и жанр — так показана проверка ввода.

Стандартные коллекции Java, без сторонних библиотек. Пакеты не используются, все файлы лежат в `src`.

## Структура

| Файл | Что внутри |
| --- | --- |
| `Book.java` | Класс сущности: поля, конструктор, геттеры, `toString()`, `equals()`, `hashCode()` |
| `BookListManager.java` | `ArrayList` книг: add, get, set, remove, size, три способа перебора, сортировка, поиск, фильтрация. `LinkedList` — очередь читателей |
| `BookSetManager.java` | `HashSet` уникальных жанров и `HashSet<Book>` для демонстрации `equals()`/`hashCode()` |
| `BookMapManager.java` | `HashMap<Integer, Book>` — каталог по ID: put, get, containsKey, remove, entrySet |
| `Main.java` | Запуск демонстрации всех операций и проверка ввода пользователя |

## Что демонстрирует программа

| Раздел в консоли | Требование |
| --- | --- |
| 1 | ArrayList: добавление, получение по индексу, изменение, удаление, размер |
| 2 | Перебор списка через `for`, `for-each` и `Iterator` |
| 3 | LinkedList: `addFirst()`, `addLast()`, `getFirst()`, `removeFirst()` |
| 4 | HashSet: `add()`, `remove()`, `contains()`, дубликаты не добавляются |
| 5 | `equals()` и `hashCode()` предотвращают дублирование объектов `Book` в HashSet |
| 6 | HashMap: `put()`, `get()`, `remove()`, `containsKey()`, `entrySet()`, повторный ключ заменяет значение |
| 7 | Сортировка через `Comparator`: `list.sort()` по названию и `Collections.sort()` по году |
| 8 | Поиск книги по названию и фильтрация по жанру |
| 9 | Ввод с клавиатуры с проверкой некорректных значений |

## Почему выбраны List, Set и Map

- **List (ArrayList)** — основной список книг. Книги хранятся в порядке добавления, к ним нужен доступ по индексу, список легко сортировать, и в нём допустимы повторы (например, несколько экземпляров одной книги).
- **LinkedList** — очередь читателей на популярную книгу. Он быстро добавляет и удаляет элементы в начале и в конце, не сдвигая остальные.
- **Set (HashSet)** — жанры. Жанр не должен повторяться: HashSet сам отбрасывает дубликаты и быстро проверяет `contains()`.
- **Map (HashMap)** — каталог книг по ID. ID уникален, и по нему нужно сразу найти книгу, не перебирая весь список.
